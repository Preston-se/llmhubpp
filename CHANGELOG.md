# Changelog

## 1.261112.2

- Localize settings in Simplified Chinese and English, including shared index controls, the settings home, configuration dialogs, and Safe Guard settings.
- Use Obsidian’s language for built-in help labels and keep custom names as entered.
- Add a Chinese repository home, an English README, illustrated setup and indexing flows, and a repeatable development and release guide.


## 1.261112.1 · First Windows x64 beta

- Unified desktop build packages the offline Wiki, Safe Guard, editable Inbox preset, and Windows terminal runtime.
- Knowledge-base answers work with compatible local and API text models. Citations point to the excerpt used for the answer. The first use of a new remote destination explains what it will receive.
- Each edited note waits 600 seconds by default before indexing. The wait can be set from 5 to 900 seconds. Closing a note offers to update it now, wait again, or keep the existing index.
- The status-bar task center shows queued index updates and their due times, with completed, failed, and cancelled work under recent history.
- The first approval for the DeepSeek search MCP can be remembered across chats. Chat reports search authorization, connection, and service errors.
- The chat composer expands when you interact with it and keeps unsent text and attachments with their conversation.
- Embedding credentials follow the configured destination. Combined indexes resolve each child connection independently.
