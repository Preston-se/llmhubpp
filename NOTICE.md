# Included components and compatibility

LLM Hub 0.36.7: Takeshi Morita (@takeshy), the original author and a credited contributor to Llmhub++. MIT. See [the upstream license](https://github.com/takeshy/obsidian-llm-hub/blob/0.36.7/LICENSE).

Safe Guard 0.6.2: developed for this project and licensed under MIT. The project archive supplied the reference JavaScript and CSS. The unchanged JS baseline is `vendor/safe-guard-0.6.2.js` (SHA-256 `40b147f1c7fe08a219fcef15ce9f4df957f8c59cb10ab7bd0fa7b272c7ff3771`). The adapted runtime retains business methods and interface strings. `src/safeguard/runtime.test.ts` checks method equivalence.

Shared library `obsidian-llm-hub-common` 0.1.3: Takeshi Morita (@takeshy), MIT. The `vendor/` archive includes its license. The build bundles parts of the library into `main.js` and `styles.css`. See [the pinned source and license](https://github.com/takeshy/obsidian-llm-hub-common/tree/c55004ea35ad8bc559e7b8d09cac915fd584e34c).

Terminal runtime: `node-pty` 1.1.0 (Christopher Jeffrey, Daniel Imms, and Microsoft, MIT), WinPTY (Ryan Prichard, MIT), the Node.js API collaborators' `node-addon-api` 7.1.1 headers (MIT), and ConPTY binaries from Microsoft Windows Terminal. The ZIP supplies their licenses and notices under `node_modules/node-pty/`. The terminal host uses an installed Node executable (`node` or `LLMHUBPP_NODE_PATH`). Windows Obsidian opens the configured CLI in an external terminal. See [node-pty](https://github.com/microsoft/node-pty/tree/v1.1.0), [WinPTY's license](https://github.com/microsoft/node-pty/blob/v1.1.0/deps/winpty/LICENSE), [node-addon-api's license](https://github.com/nodejs/node-addon-api/blob/v7.1.1/LICENSE.md), and [Windows Terminal's license](https://github.com/microsoft/terminal/blob/v1.23.12811.0/LICENSE).

`THIRD_PARTY_NOTICES.txt` in the ZIP contains license texts for the bundled npm packages, additional notices for PDF and compression code, and credit for Obsidian Skills by Steph Ango. Adobe Core 14 font metrics are distributed with the original notice at `licenses/adobe-core14/MustRead.html`. See [pinned supplemental license texts](https://github.com/Preston-se/llmhubpp/tree/main/vendor/licenses).

Source-Auto-Ingest: the Inbox workflow and scripts were developed for this project and use the project's MIT license. The preset remains editable. Format repair normalizes inline XLSX strings in a temporary conversion copy. Managed imports archive each independent document in its own format/name directory and stream large Markdown into bounded parts plus an overview. Cross-file grouping requires an explicit GroupName. The task monitor supports cooperative pause/resume and cancellation. Complete documents are committed through verified paired generations, and successful embedding batches are cached for recovery. Task records persist across restart and restore paused until the user explicitly continues. Closing with unfinished work prompts to save before exiting. Arbitrary custom scripts are never replayed automatically. The conversion scripts call existing PowerShell, Pandoc and 7-Zip installations.

Compatibility namespaces (workspace files, sidecars, CSS, events, skills and device secret IDs) remain unchanged to preserve existing data and integrations. Only enable llmhubpp in a migrated vault. First-run import copies old plugin settings after backing up their exact bytes to llmhubpp/legacy-backup; existing llmhubpp settings are never replaced. Explicit legacy shortcut bindings are copied to new command IDs after a hotkeys.json backup; existing new bindings and old bindings are retained. Backups can contain credentials and must remain private. Rollback: disable llmhubpp, restore a separate pre-migration vault snapshot if runtime data changed, and re-enable the preserved old plugins.
